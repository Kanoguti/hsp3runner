# hsp3runner - HSP3言語用コマンドラインコンパイラ

2026 Kanoguti

## このソフトウェアについて

HSP3言語用のコマンドラインコンパイラです。主にWindowsのPowerShellやコマンドプロンプト上からHSP3言語スクリプトファイルを実行したり、実行ファイルを生成することができます。

## 注意事項

- このソフトウェアを動作させるには、PowerShellがインストールされているWindows環境が必要です。コマンドプロンプト上でもこのツールは動作しますが、ツールの内部でPowerShellも使用しています。
- 「HSP3.8beta1」で動作を確認と開発をしております。
- 後述の「基本的な使い方」ではHSP3の互換性を考慮して「hsp3runner32.exe」を使用した例を記述しておりますが、「HSP3.8」以降のバージョンでは「hsp3runner64.exe」を使用することをおすすめします。
- スクリプトファイルの名前には、英数字とアンダーバーやハイフンのみで記述することをおすすめします。

## 基本的な使い方

今回の使用例では、以下の設定でHSP3言語スクリプトファイルを実行します。

- 使用する「hsp3runner」の実行ファイル : `hsp3runner32.exe`
- HSP3のシステムフォルダのパス : `C:\hsp38`
- 実行するHSP3言語スクリプトファイルのパス : `C:\Path\To\MyProject\main.hsp`
<br>ファイルの内容は以下の通りです。

```
mes "Hello, world."
stop
```

- デバッグ情報を「start.ax」ファイルに書き込む処理を有効にする
- 実行時にデバッグウィンドウを表示する

### 1 - 「hsp3runner32.exe」ファイルの移動

「hsp3runner32.exe」ファイルをHSP3言語のシステムフォルダの中に移動させてください。

### 2 - コマンドの文法

これからPowerShellやコマンドプロンプトに入力するコマンドは、以下の形式です。

`[HSP3のシステムフォルダ]\hsp3runner32.exe --[オプション1の名前] [オプション1の内容] --[オプション2の名前] [オプション2の内容] [(以降任意の回数記述してください。)]`

### 3 - コマンドの入力と実行

PowerShellを起動し、カレントディレクトリを「`C:\Path\To\MyProject`」に設定し、以下のコマンドを入力し実行すると、ウィンドウが表示され、ウィンドウ内に「Hello, world.」と表示されます。

`C:\hsp38\hsp3runner32.exe --source "$pwd\main.hsp" --debug-info on --debug-window on`

コマンドプロンプトの場合は以下の通りです。

`C:\hsp38\hsp3runner32.exe --source "%CD%\main.hsp" --debug-info on --debug-window on`

表示されたウィンドウを閉じると、「hsp3runner32.exe」の処理は自動的に終了します。

### 4 - コマンドオプション一覧

hsp3runnerで使用できるオプション一覧です。オプションの内容に`[path]`を指定するオプションには、「`"`(ダブルクォーテーション)」で囲んで入力することをお勧めします。

- `--source [path]`<br>処理対象とするHSP3スクリプトファイルを絶対パスで指定します。このオプションを省略すると、「hsp3runner」の実行ファイルがあるフォルダ内の「`main.hsp`」に設定されます。
- `--mode [run/build]`<br>処理対象とするHSP3スクリプトファイルを使って「スクリプトの実行」を行うか「exeファイルをビルド」するかの設定を行います。「`run`」にすると「スクリプトの実行」、「`build`」にすると「exeファイルをビルド」を行います。このオプションを省略すると、「`run`」に設定されます。
- `--system [path]`<br>HSP3言語のシステムフォルダを絶対パスで指定します。例えば「`"C:\hsp38"`」のように入力します。このオプションを省略すると、「hsp3runner」の実行ファイルがあるフォルダに設定されます。
- `--common [name]`<br>HSP3言語のシステムフォルダ内にある「common」フォルダの名前を指定します。ここで指定するフォルダの名前は「`--system`」オプションで指定したパスから見たフォルダ名を相対パスで指定します。ほとんどの場合、デフォルト値である「`common`」のままで大丈夫です。
- `--debug-info [on/off]`<br>処理対象とするHSP3スクリプトファイルのコンパイルをする際に、デバッグ情報をオブジェクトファイルに書き込むかの設定を行います。「`on`」にすると書き込みが有効になります。このオプションを省略すると、「`off`」に設定されます。
- `--debug-window [on/off]`<br>処理対象とするHSP3スクリプトファイルの実行をする際に、デバッグウィンドウを表示するかの設定を行います。「`on`」にすると表示されます。このオプションを省略すると、「`off`」に設定されます。
- `--string [shift-jis/utf-8]`<br>処理対象とするHSP3スクリプトファイルがどの文字コードで記述されているかを指定します。このオプションを省略すると、「`hsp3runner32.exe`」を使用している場合は「`shift-jis`」、「`hsp3runner64.exe`」を使用している場合は「`utf-8`」に設定されます。
- `--charset [shift-jis/utf-8]`<br>処理対象とするHSP3スクリプトファイルをコンパイルする際に、スクリプト内部の文字列をどの文字コードとしてコンパイルするかを設定します。「`--string`」オプションを「`shift-jis`」した際にこのオプションを「`utf-8`」に設定すると、スクリプトファイル内の文字列を「UTF-8」に変換してコンパイルされます。尚、「`--string`」オプションを「`utf-8`」、「`--charset`」オプションを「`shift-jis`」にして、スクリプトファイル内の文字列を「UTF-8」から「Shift-JIS」に変換させることはできません。このオプションを省略すると、「`hsp3runner32.exe`」を使用している場合は「`shift-jis`」、「`hsp3runner64.exe`」を使用している場合は「`utf-8`」に設定されます。
- `--bit [32/64]`<br>処理対象とするHSP3スクリプトファイルをコンパイルする際のデフォルトランタイムのビット数を指定します。このオプションを省略すると、「`hsp3runner32.exe`」を使用している場合は「`32`」、「`hsp3runner64.exe`」を使用している場合は「`64`」に設定されます。
- `--emscripten [on/off]`<br>処理対象とするHSP3スクリプトファイルをコンパイルする際、「Emscripten」向けにコンパイルするかの設定を行います。このオプションを省略すると、「`off`」に設定されます。
- `--obj [name]`<br>処理対象とするHSP3スクリプトファイルをコンパイル後に生成されるオブジェクトファイルの名前を設定します。このオプションを省略すると、「`start.ax`」に設定されます。
- `--option [string]`<br>おまけ機能です。処理対象とするHSP3スクリプトファイルを実行する際のコマンドラインオプションを文字列で設定します。文字列内にスペースが含まれる場合、「`"`(ダブルクォーテーション)」で囲むことをおすすめします。現状、文字列が正確にコマンドラインオプションとして確実に機能するかは保証しません。このオプションを省略すると、空の文字列に設定されます。
